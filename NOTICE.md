# Notice

AgentPulse was inspired by the human-in-the-loop architecture documented by
VibePulse (https://github.com/niclasvestlund-YT/vibepulse), an MIT-licensed
project by Niclas Vestlund. In particular, VibePulse demonstrated the useful
properties of binding a remote decision to one pending request, failing back
to the terminal on timeout, and using Claude Code/Codex interaction hooks
rather than terminal keystroke injection.

AgentPulse is a separate implementation aimed at a mobile/PWA workflow.
